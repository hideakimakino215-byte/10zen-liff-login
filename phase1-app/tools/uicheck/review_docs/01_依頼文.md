# 依頼: 10ZEN 会員証・体質チェックの最終チェック(UI と実装)

## 背景
- 10ZEN は東京・青山の薬膳レストラン(42席)。運営は薬日本堂(漢方の専門店)のグループ。
- 紙と古い仕組みの会員制度を、**LINE の中で開く会員証(LIFF)** に置き換える。本番開始の直前で、いまは試験運用中。
- 会員証には「1分体質チェック」(15問+今日の食事の気分 → 東洋医学の五行の考え方で体質の傾向を出し、お料理と五巡茶(店のお茶)をおすすめする)が付く。
- お客様の画面(会員証・体質チェック・Web 版・店頭の QR)は **日本語・英語・中国語(簡体字)**。スタッフ画面は日本語のみ。
- 自動テスト 310件は合格済み。機能が動くことは確認済みなので、**今回見てほしいのは「人が使ってどうか」と、それに関わる実装** です。

## 使う人と場面
| 使う人 | 端末・場面 | 気をつけたいこと |
|---|---|---|
| お客様(日本人) | 自分のスマホの LINE。席で・会計の前に | 初めてでも迷わない。高齢の方も読める |
| お客様(訪日客) | 同上。英語・中国語 | 日本語が混ざって意味が通じない所がないか |
| お客様(来店前) | Web 版の体質チェック(SNS・Google から) | ログインなしで最後まで進めて、LINE の登録に進みたくなるか |
| スタッフ | 自分のスマホ・レジ横の端末。混雑時に片手で | 6桁のコードを入れて確定するまでが速く、間違えにくいか |
| 店長・本部 | スマホ・PC | 集計・目標の画面が読み取りやすいか |
| 店頭タブレット | 置きっぱなし。お客様が見て QR を読む | 遠くから見て分かるか。3か国語の自動切り替えが自然か |

## 見てほしい観点(この4つが中心)
1. **全体の統一感**: 画面どうしで、色・文字の大きさ・ボタンの形・言い回し・用語(例: 「ポイント」「pt」、「五巡茶」の呼び方)がそろっているか。お客様の画面とスタッフ画面で、ブランドとしてまとまっているか。
2. **見やすさ**: 文字の大きさ・行間・コントラスト(背景と文字の濃さの差)・情報の詰め込みすぎ・スクロールの長さ。暗い場所・高齢の方・小さな画面。
3. **わかりやすさ**: 文言が一度読んで分かるか。専門用語(五行・五臓など)の扱い。英語・中国語が自然か(機械翻訳っぽさ・意味のずれ)。エラーや「できなかったとき」の案内が次にすることを示しているか。
4. **直感的に使えるか**: 次に押すものが迷わず分かるか。押せる所が押せるように見えるか。戻る・取り消しができるか。タップする所の大きさ(目安 44px 以上)。

### 実装の面で見てほしいこと(UI に関わる範囲)
- 画面の崩れ・はみ出し・重なりが起きそうな書き方(長い名前・長い英文・小さな画面・文字を大きくする設定)。
- 読み上げ(VoiceOver)やキーボードで使えるか(ラベル・見出し・フォーカス)。
- 言語の切り替えの漏れ(英語・中国語の画面に日本語が残る所。ただし「決定事項」の例外を除く)。
- 文言が画面ごとに直書きされていて、同じ意味なのに言い回しが違う所。
- 読み込み中・通信失敗・時間切れの表示が抜けている所。

## 見なくてよいこと
- サーバー・データベース・権限の安全性(別に監査済み)。
- `03_決定事項と前提.md` に書いた決定事項。**反対意見がある場合は、指摘とは別に「決定事項への意見」として短く書いてください**(採用するかはこちらで判断します)。
- メニュー名・価格などの中身(未確定)。

## 出力の形
1. **総評**(3行以内): いちばん効く改善はどこか。
2. **指摘の表**(重要度の高い順):

| No | 重要度 | 画面・場所 | 観点 | 指摘 | 理由(誰が・どう困るか) | 修正案(具体的に) |
|---|---|---|---|---|---|---|
| 1 | 高 | A-2 英語 | わかりやすさ | … | … | 文言なら変更後の文。色・大きさなら値 |

   - 重要度: **高**=本番前に直したい(誤解・操作できない・ブランドを損なう) / **中**=早めに直したい / **低**=余裕があれば。
   - 「画面・場所」は画面集の番号(例: A-2 英語)か、ファイルと行(例: src/app-reference/card.html:182)。
   - 修正案は、文言なら **変更後の文そのもの**(日本語・英語・中国語のどれか)、見た目なら **具体的な値**(例: 文字 13px → 15px)。
3. **良い点**(3つまで。変えないほうがよい所)。
4. **決定事項への意見**(あれば)。
5. **確かめきれなかったこと**(実機でしか分からない点など)。

指摘は多すぎるより、**本番前に効くものを優先して 30件以内** にしてください。
