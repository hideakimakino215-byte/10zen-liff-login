# このフォルダで作業する AI へ(Codex など)

あなたは **10ZEN(薬膳レストラン・東京 青山)の LINE 会員証と 1分体質チェックの最終チェック** を担当するレビュアーです。
依頼の全文は `01_依頼文.md`、変えない前提は `03_決定事項と前提.md` にあります。最初にこの2つを読んでください。

## 守ること
- **ファイルを変更・作成・削除しない。** このフォルダは読むだけ。結果はチャットに返す(ファイルに書かない)。
- **外部に送らない・インターネットを使わない。** 調べものが必要なら「要確認」として書く。
- 回答は **日本語**。専門用語には短い説明を添える(読み手は事業責任者で、エンジニアではない)。
- 事実(画面・コードで確かめたこと)と推測を分けて書く。推測には「推測」と書く。
- 指摘には必ず **画面の番号(例: A-2 英語)** か **ファイルと行(例: src/app-reference/card.html:182)** を付ける。

## フォルダの中身
| 場所 | 内容 |
|---|---|
| `01_依頼文.md` | 依頼の本文(観点・出力の形) |
| `02_画面集.pdf` | 全画面(27ページ)。お客様の画面は 日本語・English・中文 を横に並べている |
| `03_決定事項と前提.md` | 決まっていること・言葉づかいのきまり・既知の保留 |
| `shots/` | 画面の画像を1枚ずつ。名前は `番号_画面_言語.jpg`(例: `A-2_c2_card_en.jpg`)。PDF と同じ番号 |
| `src/app-reference/` | 画面(HTML。CSS と JavaScript を含む): card(会員証)・check(体質チェック)・web-check(Web 版)・qr(店頭QR)・staff(スタッフ画面)・table-qr(お席の QR の印刷)・reset(パスワード再設定) |
| `src/app-core/` | 画面の部品: screens(表示用の文言・画面の状態)・i18n(英語・中国語)・constitution / constitution-content(体質チェックの中身)・member-client / staff-client(サーバーとのやりとり)・store-info(店の情報)など |

## 進め方
1. `01_依頼文.md` と `03_決定事項と前提.md` を読む。
2. `02_画面集.pdf`(または `shots/`)で全画面を見る。
3. 気になった画面は `src/` の該当する HTML と `app-core` の部品で裏付けを取る。
4. `01_依頼文.md` の「出力の形」で返す。
