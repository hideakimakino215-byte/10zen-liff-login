# ペルソナ実験(AI がなりきって操作)の結果(2026-10-17)

**方法:** 手元の使い捨ての DB と画面(本番と同じ設定。来店の受付時間だけ終日)で、7人の人物像になりきって最初から最後まで自動で操作し、各画面の写真・タップ数・小さい文字・横スクロールを記録して見直した。人物はすべて架空。本物の人の試験(②)は週明けに牧野さんが行う。

| 人物像 | 試した流れ | 結果 |
|---|---|---|
| P1 初めてランチの会社員 | お席の QR → 未登録 → 会員登録 → 体質チェック → 注文 | 通る。ただし遠回り(下の 1・2) |
| P2 常連の60代(iPhone SE) | 会員証 → ポイント 500pt を使う → スタッフが確定 | 通る。文字が小さい・コードの案内がない(4・5・6) |
| P3 健康志向(Instagram から) | Web 版 → LINE で登録 → 会員証 | 通る。Web の結果は引き継がれない(7) |
| P4 食物アレルギーがある | お席の QR → 体質チェック → 結果 | 注文ボタンの直前に「アレルギーはスタッフへ」が出る。会員証には案内なし |
| P5 LINE を使わない・観光客 | Web 版・お席のカード | 日本語だけ(8)。カードの小さい QR からは注文できる |

| P7 混んでいるときのスタッフ | ポイント使用とチケットの確定 | 1件あたりコード入力+2タップ。問題なし |

## 見つかったこと(優先順)

1. **お席の QR から入った未登録の人が遠回り。**「会員証で会員登録をしてから…」→ 会員証 → 登録 → 自分で「1分体質チェック」を探す(3画面+探す)。案: 体質チェックの画面で、その場で「会員登録して体質チェックへ」の1ボタン。
2. **結果画面で注文ボタンが遠い(約1.6画面下)。** 初めての人は「今日の傾向」と「あなたの体質」が同じ内容で2回(五角形も2つ)出て、履歴も1件だけ。案: 1回目は「あなたの体質」と履歴を出さない。お席の QR から来た人は、おすすめの一品と注文を結果のすぐ下に。
3. **会員証の裏に旧来の「30秒体質チェック」(Tally)のリンクが残っている。** 新しい「1分体質チェック」と2つあって迷う。案: 裏の案内を新しい体質チェックに差し替える。
4. **ポイント使用のコードに「スタッフにお見せください」がない**(チケットにはある)。
5. **小さい文字(10.5〜12px)**: 「保有ポイント」「累計」「タップで表裏を切り替え」など。案: 13px 以上に。
6. **ポイント使用は数字の入力が必要。** 案: 「500」「1,000」「全部」のボタン。
7. **Web 版の結果が LINE 登録後に引き継がれない**(もう一度15問)。案: 段階②(結果の引き継ぎ)。少なくとも、登録の後に体質チェックへ直接案内する。
8. **日本語だけ。** 案: お席のカードに英語の1行(例: Scan to order)。Web 版の英語は将来。

**問題なしと確かめたこと:** どの画面も横スクロール・エラーなし。紹介の流れ・チケット・ポイント使用・スタッフの確定は迷う所なし。アレルギーの案内は注文の直前に出る。

**限界:** 自動操作で、実際の人の迷い方・読む速さは分からない(②で確かめる)。LINE アプリそのもの(ログイン・カメラ)は再現していない。

## 追加で見つかったこと

9. 体質チェックを途中でやめると、最初から(同意も)やり直し。案: 回答を端末に一時保存して続きから。
10. **ポイントの有効期限(最後の来店・利用から12か月)が会員証に出ていない。** データは届いているが画面に表示していない。案: 期限まで60日を切ったら「ポイントの有効期限: ○年○月○日」を出す。
11. **ポイント使用で空のまま押すと「nullpt」と出る不具合。** 修正済み(「使うポイントを入力してください」)。
12. ランクが上がったときのお祝いのお知らせがない。案: 「AMBER に上がりました。豆花のチケットをお届けしました」。
13. スタッフ画面で桁が足りないコードにも「期限切れの可能性」と出る。案: 「6桁で入力してください」。
14. バランス良好の人のおすすめの一品・お茶に理由の説明がない。案: 「今の季節に合わせたおすすめです」を添える。
15. 「登録で 100pt」の案内が、キャンペーン中(10/10〜10/31 は 200pt)と合わない(店頭タブレット・会員証の登録前)。案: キャンペーン中は 200pt と出す。

**牧野さんの決定(2026-10-17):** 結果画面の「あなたの五巡茶(あなたの体質から)」を「あなたにおすすめの五巡茶」に変更(Web 版も同じ)。反映済み。
