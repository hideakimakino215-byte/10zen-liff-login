# 1分体質チェックの設計(2026-10-15)

- **決定者:** 牧野さん(10ZEN 青山店 事業責任者)。2026-10-15 にテキストで1問ずつ決定。
- **状態:** 設計は確定。実装はまだ。会員証の本番開始(運営変更の後)に合わせる。
- **公開リポジトリのため、教材の本文は入れない。** 教材(薬日本堂漢方スクールのテキスト)は非公開の Google ドライブにあり、読むだけにする。ここに書くのは、教材の考え方(五行配当表など)をもとに自前の言葉で作った内容だけ。

## 1. 位置付けと方針

- **ターゲット:** 販促計画(2026-08)のとおり、ライトな健康志向の方(20〜30代の女性や会社員など)。「美味しいから来て、気づけば健康に」。専門的な健康志向の方には寄せない。
- **10ZEN の位置付け:** 薬日本堂との相互送客の入り口。
- **言葉:** 難しいことを並べない。正しい理論と正式な名称を裏に持ち、表はわかりやすくする(3段構え)。
  1. **表に出す言葉:** 例「モヤモヤ渋滞タイプ」とひとことの説明。
  2. **正式な名称:** タップした人だけに見せる。五行・五臓・状態の名称。
  3. **次の一歩:** 「もっと詳しく知りたい方は、薬日本堂の漢方相談へ」。
- **名前:** 「1分体質チェック」(旧「30秒体質チェック」。15問になったため変更)。

## 2. タイプ(五行の5タイプ)

| 五行 | 五臓 | 状態の名称 | 表に出す言葉 |
|---|---|---|---|
| 木 | 肝 | 気滞(きたい) | モヤモヤ渋滞タイプ |
| 火 | 心 | 偏熱(へんねつ) | カッカ熱こもりタイプ |
| 土 | 脾 | 脾虚(ひきょ) | 消化パワー不足タイプ |
| 金 | 肺 | 燥(そう)・津虚(しんきょ) | うるおい不足タイプ |
| 水 | 腎 | 陽虚(ようきょ) | ぽかぽかパワー不足タイプ |

- 旧版(Marquiz・本番 DB の `diagnosis_patterns`)からの変更: 火を「湿熱」から「偏熱」へ、金を「陰虚」から「燥・津虚」へ。教材の五行配当表で、湿は土・燥は金の気候にあたるため。
- **正式な名称は、公開前に薬日本堂の方に確認してもらう。**

## 3. 質問と判定

**答え方:** 全問「よくある(2点)/ときどき(1点)/あまりない(0点)」の3択。

| 五行 | 質問 |
|---|---|
| 木 | 1. イライラしたり、気分の浮き沈みが大きい / 2. 目が疲れやすい・かすみやすい / 3. ため息が多い・お腹や胸が張る |
| 火 | 4. 寝つきが悪い・夢をよく見る / 5. 顔がほてる・赤くなりやすい / 6. ドキドキしやすい・汗をかきやすい |
| 土 | 7. 食後に眠くなる・胃がもたれる / 8. むくみやすい・湿気の多い日はだるい / 9. 考えすぎると食欲が落ちる・甘いものが欲しくなる |
| 金 | 10. 肌・髪・のどが乾燥しやすい / 11. 風邪をひきやすい・鼻やのどの不調が出やすい / 12. 便が硬い・出にくい |
| 水 | 13. 手足や腰が冷えやすい / 14. 夜中にトイレに起きる・トイレが近い / 15. 腰や膝がだるい・髪のハリが気になる |

- **16. 食事の気分(5択):** 選択肢はメニューが決まったら差し替える(メニューの設計は別件)。
- **判定:** 五行ごとの合計(0〜6点)を比べ、一番高い五行が主なタイプ。**同点は今の季節の五行を優先**(春=木・夏=火・土用=土・秋=金・冬=水)。**全部1点以下は「バランス良好」**。
- 旧版の判定(桁の優先順で、木が1つでもあれば木)は木に偏るため廃止。

## 4. 使う流れ

| 場面 | 内容 |
|---|---|
| 初回 | 会員証から体質チェック(15問+気分、約1分)→ 結果 |
| 2回目以降の来店 | 店頭QRで来店ポイント → 会員証に「今日の体調」3問(約10秒)→ 今日のおすすめ |
| 季節の変わり目 | 会員証に「季節が変わりました。体質チェックをもう一度」と案内 |

**今日の体調(1問1タップ):** 選んだ五行に2点を足し、今日のおすすめに反映する。

| 質問 | 選択肢 |
|---|---|
| A. 今日のからだは? | 冷えている(水)/ほてっている(火)/ふつう |
| B. 今日の調子は? | 疲れ・胃が重い(土)/ストレス・張り(木)/元気 |
| C. 今日気になることは? | 乾燥・のど(金)/むくみ・だるさ(土)/特になし |

## 5. 結果の画面

1. タイプ名とひとことの説明
2. 五角形のグラフ(タップで五行・五臓・正式名称)
3. 今日のおすすめの一品(体質×食事の気分。今日の体調で調整。おすすめ表は差し替えられるデータにする)
4. あなたの五巡茶とその曜日(例「金曜日はあなたのお茶の日」)。今日のお茶とひとこと
5. 季節のひとこと
6. 薬日本堂への案内(「もっと詳しく知りたい方は、薬日本堂の漢方相談へ」)
7. 「体質の傾向の目安で、医療的な診断ではありません」の表示

## 6. 五巡茶(薬日本堂)の日替わり

- **漢方茶を薬日本堂の「五巡茶」(木・火・土・金・水の5種)に変える予定。** 表記は「五巡茶」で統一する。
- **曜日の名前どおりに出す:** 火曜=火、水曜=水、木曜=木、金曜=金、土曜=土。月曜・日曜=今の季節の五行。
- 1日1種類を、温かいもの・冷たいものの両方で出す。ランチは無料で飲み放題、ディナーは有料の飲み放題(AMBER 以上は無料。ランク特典の設計を参照)。
- 体質のタイプと同じ五行のお茶を「あなたのお茶」とする。
- **水の五巡茶:** 原材料にはとむぎ(教材では微寒)などを含むため、冷えのタイプの方には「温かいほうで」と添える。
- 原材料は公式ページの記載を検索結果で確認したもの。対応表とあわせて、公開前に薬日本堂に確認する。

## 7. 記録・同意・言葉づかい

1. **保存するもの:** 15問の回答・五行ごとの点数・タイプ・今日の体調・日時(判定を直しても計算し直せるよう、回答も残す)。
2. **同意:** 初回に「結果を会員証に記録し、おすすめとお店の改善に使います」と示して同意を取る。
3. **薬日本堂への共有:** 集計だけ。個人の結果は、お客様が薬日本堂で自分の画面を見せる形にする(別会社への個人情報の提供にしない)。
4. **診断ではないことの表示**(5の7番)。
5. **言葉づかい:** 「治る・効く・改善する」を使わない。「〜な方に」「巡りを意識したい日に」のような表現にする(五巡茶もメニューも食品のため。薬機法・景品表示法)。**公開前に薬日本堂の表現チェックの部署を通す。**

## 8. スタッフ画面で見る数字

スタッフ画面にホームを作り、「会員証」と「体質チェック」を選べるようにする。

| 区分 | 数字 |
|---|---|
| 実施 | 実施した人数・会員のうちの実施率 |
| 体質 | タイプ別の人数・五行ごとの平均(五角形) |
| 今日の体調 | 今週の傾向 |
| 効果 | 実施した人・していない人の再来店率と来店頻度の比較 |
| 送客 | 結果画面の「薬日本堂の漢方相談へ」が押された数 |

- **権限:** 店長・本部はすべて。スタッフは「今週の体調の傾向」だけ。
- **薬日本堂で実際に相談・購入した人数:** 会員番号を記録してもらうか、10ZEN 経由の案内コードを出すか。薬日本堂との相談で決める。
