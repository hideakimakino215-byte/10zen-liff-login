**途中で起きたことと対処**
- DB の追加を apply_migration で送ると、文が大きく(約35KB)通信が60秒で切れた(3回とも DB には何も入らず、自動で取り消し)。
  → DB 自身に公開リポジトリの**固定したコミット(bff4b2a)**からファイルを取得させ、手元のファイルと md5 が一致したときだけ実行する方式に変更。
    さらに「適用 → 指紋の照合 → 一致しなければ全部取り消し」を1つの取引にまとめた(手元で通し予行をしてから本番へ)。
- 関数の組み立てで、esm.sh の `supabase-js@2`(最新版 2.118.0)が壊れていて失敗。→ `npm:@supabase/supabase-js@2.45.4` に版を固定(3c9ea6f)。staff-qr は今回更新していない(次に更新するときもこの形で組み立てられる)。
